# SmartCampus – Campus Complaint Management System

## About
SmartCampus is a web-based application that helps students report campus problems and allows administrators to manage and track complaints.

## Problem
Students often face difficulties reporting campus issues and tracking their resolution.

## Proposed Solution
A centralized platform where students can submit complaints and administrators can view and update complaint statuses.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- SQLite

### Integration
- REST API
- Fetch API
- JSON

## Main Features
- Submit complaints
- View complaints
- Track complaint status
- Manage complaints

## Project Structure
- frontend – User interface
- backend – Server and database operations
